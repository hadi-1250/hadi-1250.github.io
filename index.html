Pertemuan 5

Hyperlink

Materi Hyperlink membahas penggunaan tautan dalam HTML yang berfungsi untuk menghubungkan satu halaman web dengan halaman lain, baik dalam satu website maupun ke website yang berbeda, serta mengarahkan pengguna ke bagian tertentu dalam halaman yang sama. Hyperlink dapat diterapkan pada teks maupun gambar dengan menggunakan atribut href pada tag , dan dibedakan menjadi beberapa jenis, yaitu link relatif untuk menghubungkan antarhalaman dalam satu website, link absolut untuk menuju halaman pada website lain, link anchor untuk mempermudah navigasi pada halaman web yang panjang dengan melompat ke bagian tertentu, serta link email yang digunakan untuk membuka aplikasi email dan langsung mengirim pesan ke alamat yang dituju. Dengan pemanfaatan hyperlink yang tepat, halaman web menjadi lebih interaktif, mudah dinavigasi, dan mampu menghubungkan berbagai informasi secara terstruktur .

Pertemuan 6

Bullet, Numbering, dan List

Materi Bullet, Numbering, dan List dalam Pemrograman Web 1 menjelaskan cara menampilkan daftar data pada halaman web menggunakan tag list dalam HTML agar informasi tersusun rapi, terstruktur, dan mudah dipahami oleh pengguna. Pembuatan daftar berurutan dilakukan dengan ordered list (< ol >) yang menampilkan penomoran berupa angka, huruf, atau romawi sesuai kebutuhan, sedangkan daftar tidak berurutan menggunakan unordered list (< ul >) dengan simbol bullet seperti disc, circle, atau square. Selain itu, terdapat menu list (< menu >) yang digunakan untuk menampilkan daftar item tanpa nomor dan bullet, serta definition list (< dl >) yang berfungsi menjelaskan suatu istilah melalui pasangan data term (< dt >) dan data definition (< dd >). Dengan memanfaatkan berbagai jenis list ini, pengembang web dapat menyajikan informasi seperti menu, prosedur, daftar item, maupun penjelasan istilah secara sistematis sehingga tampilan halaman web menjadi lebih jelas, informatif, dan mudah dinavigasi.

Pertemuan 7

Tabel

Materi Tabel menjelaskan cara menampilkan dan mengatur data dalam bentuk baris dan kolom menggunakan tag < table > pada HTML, yang sering dimanfaatkan untuk menyusun informasi maupun mengatur tata letak tampilan halaman web. Struktur tabel terdiri dari baris (< tr >), kolom atau sel data (< td >), serta header tabel (< th >), dan dapat dilengkapi dengan judul tabel menggunakan < caption >. Selain itu, tabel memiliki berbagai atribut seperti border, cellpadding, dan cellspacing untuk mengatur tampilan garis dan jarak, serta align, valign, colspan, dan rowspan untuk mengatur perataan dan penggabungan baris maupun kolom. Dengan memahami penggunaan tabel dan atributnya, mahasiswa dapat menyajikan data secara rapi, jelas, dan mudah dibaca, sekaligus mengombinasikannya dengan elemen HTML lain untuk menghasilkan tampilan website yang terstruktur dan informatif .
